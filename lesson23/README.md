# Урок 23. Проект «Вертолёт» — консольная игра

На поле растут деревья 🌲 и периодически загораются 🔥. Вертолёт 🚁 набирает воду
в реке 🌊 и тушит пожары. Непотушенное дерево сгорает, пожар перекидывается на соседей.

## Запуск

```bash
cd lesson23
python3 main.py
```

Нужен Python 3.8+, сторонние библиотеки не используются. Запускать в терминале
(в VS Code — встроенный терминал, Ctrl+`).

## Управление

| Клавиша | Действие |
|---|---|
| W A S D / стрелки | полёт (работает и в русской раскладке) |
| F | сохранить игру в `save.json` |
| G | загрузить игру из `save.json` |
| Q | выход |

## Правила

| Клетка | Что происходит |
|---|---|
| 🌊 река | резервуар заполняется до максимума |
| 🔥 пожар | если есть вода: −1 вода, дерево спасено, **+100** очков |
| 🏪 магазин | за 500 очков вместимость резервуара +1 |
| 🏥 госпиталь | за 1000 очков +10 жизней |
| 🌀 гроза | −1 жизнь |
| 💭 облако | просто закрывает обзор |

Сгоревшее дерево: **−10** очков, клетка становится пустым полем 🟩.
Жизни закончились — игра окончена.

## Механика тиков

Один тик — 0.05 с. Каждые 30 тиков вырастает дерево, каждые 150 — сгорают
непотушенные пожары и появляются новые, каждые 100 — меняется погода.
Константы — в начале `main.py` и `map.py`.

## Структура

| Файл | Содержимое |
|---|---|
| `main.py` | игровой цикл, тики, отрисовка, сохранение/загрузка |
| `map.py` | поле: проверка границ, реки, деревья, пожары, магазин, госпиталь |
| `helicopter.py` | вертолёт: координаты, вода, очки, жизни |
| `clouds.py` | облака и грозы |
| `utils.py` | случайные клетки и вероятности |
| `keyboard.py` | чтение клавиш без Enter (macOS/Linux/Windows) |
